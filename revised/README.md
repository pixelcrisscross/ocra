# ORCA 5-Level Ocean Intelligence Prototype

## Pipeline
1. Gemini 2.5 Flash-Lite: natural language -> intent JSON
2. Python live-data agent: Nominatim + Open-Meteo Marine + Open-Meteo Weather + optional nearest NOAA NDBC buoy
3. Python official-web research: INCOIS-focused search without Gemini Search grounding
4. Python fusion: validation, fallback selection, completeness, risk heuristics, provenance
5. Gemini 2.5 Flash: unified JSON -> final language JSON

Only two Gemini calls are made per request. No Gemini Google Search grounding is used.

## Install

```powershell
python -m venv venv
venv\\Scripts\\activate
python -m pip install -r requirements.txt
copy .env.example .env
```

Put your key into `.env`:

```env
GEMINI_API_KEY=...
```

## Run

```powershell
python main.py
```

Example:

```text
What are the current sea conditions near Visakhapatnam?
```

## Notes

- Numeric measurements and source metadata are generated by Python, not Gemini.
- Missing values remain null/unavailable; they are never replaced with guesses.
- NOAA NDBC is used only when a nearby active station is within 500 km.
- Generic web research is evidence discovery, not a source for inventing measurements.
- This prototype is not a navigation safety system.
