# ORCA — 5-Level Ocean Intelligence Prototype

## Architecture
1. Gemini Level 1: natural language -> intent JSON
2. Python Level 2: geocoding + Open-Meteo Marine/Weather + optional NOAA NDBC observation
3. Python Level 3: independent INCOIS official-source research (no Gemini Search)
4. Python Level 4: validation, risk screening, completeness, confidence, provenance
5. Gemini Level 5: validated JSON -> language JSON

Only Levels 1 and 5 call Gemini.

## Setup

```powershell
python -m pip install -r requirements.txt
copy .env.example .env
# edit .env and add GEMINI_API_KEY
python main.py
```

You can also run directly:

```powershell
python main.py "What are the current sea conditions near Visakhapatnam?"
```

## Important behavior

- Broad requests automatically expand into the core marine/weather parameter set.
- Missing values are `status: unavailable`, never fake zeroes.
- Critical missing wave/wind inputs prevent the system from calling the result a low-risk safety assessment.
- Every acquired value carries source, URL, timestamp, type, and confidence.
- Final measurements and source lists are assembled by Python, not generated by Gemini.
- INCOIS pages are included as official evidence; a page is not treated as a numerical measurement unless a machine-readable value is actually extracted.
